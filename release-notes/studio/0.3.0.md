本版是 Rust 内核的第一个发布版：内核启动面、工具 ABI、权限判定核、bash 分析引擎与只读工具以 Rust 落地，并通过与 Go 参照实现的逐用例对照测试。

## 新增

- 内核以 Rust 重写并随本版发布：配置分层加载、会话列表与工作区树、loopback 门与 HTTP/SSE 面、桌面握手与租约，全部通过冻结契约的对拍测试 (docs/parity/LEDGER.md)
- 权限判定核（规则表、写篱笆、会话授权）与 bash 命令分析引擎（复合语句拆分、包装命令剥离、只读判定、网络路径识别）迁移为 Rust，Go 侧全部判定用例逐条移植为测试 (docs/wave-18-plan.md, docs/wave-19-plan.md)
- 只读工具面（read_file/glob/ls/grep 与工作区约束）迁移为 Rust，编号窗口读取、多编码级联、双星匹配与忽略规则行为对齐 (docs/migration-report.md)

## 修复

- 桌面内核以纯 Rust 进程启动：握手行、act 行、12 相启动日志与优雅排空与 Go 版逐字节一致 (apps/reasonix-studio-host)

## 升级须知
