# Reasonix Studio 0.1.0

The first release of the Tauri shell around the Go kernel.

- The webview loads the kernel's own page; the shell bundles the Go host and
  the built page as resources, so one package carries everything it runs.
- Live events stream from the kernel into the conversation transcript.
- Updates check this repository's releases; installation stays off until the
  signing secrets are configured on the release side.
- The legacy account surfaces (sign-in, cloud backup, market publishing, phone
  reminders) are retired. Phone access stays as the built-in LAN/Tailscale
  pairing door, and a hosted web page can pair with a desktop through the
  self-hosted relay worker (see `workers/remote/`).
