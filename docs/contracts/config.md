## 0. Resolution order (config.go:1-4 package doc + reasonix.example.toml:2)

flag > project config (`./reasonix.toml`, falling back to `.reasonix/reasonix.toml`) > user `config.toml` (OS user-config dir, i.e. Reasonix home) > built-in defaults. Secrets never stored in config files; providers name env vars via `api_key_env`, key values live in Reasonix home `.env`.

## 5. Model resolution (config.go:1381-1523)

- Provider(name): exact-name lookup. ResolveModel(ref) (1401-1417): "provider/model" → that model; provider name → its default model; bare model name → first provider that lists it; handles stand-ins, desktop provider_access retargeting, folded deepseek refs.
- ResolveModelWithFallback (1423-1450): try ref; then default_model (if different and Configured() and AnswersChat); then first provider with models+key+chat; returns "provider/model", fallback flag.
- resolveNewSessionChatModel (1465-1523): default_model resolved and Configured → use it; keyless valid default kept for recovery UI; unknown default preserved for CLI error (preserveUnknownDefault); else first chat provider (Configured preferred over keyless); keylessFallback last.
- Validate (1539-1557) errors verbatim: `unknown model %q (configured: %s)`; `provider %q: base_url is required`; `provider %q: api_key_env %q is invalid; use letters, numbers, and underscores, not a model name`; `provider %q: no stored key for %s in %s; run 'reasonix setup'`.
- WriteFile (1370-1379): atomic + fsync'd write so an interrupted write can never truncate the main config (#4615, #4708); user scope resolves config read path first.
